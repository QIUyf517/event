## 方法

运行：

```powershell
.\.venv\Scripts\python.exe -m scripts.accept_phase2_live --as-of 2026-10-06
```

脚本以 SQLite `mode=ro` 打开原实时数据库，并用 SQLite backup API 创建临时副本。所有研究任务、报告和工具调用只写入临时副本；脚本结束后副本自动删除。此过程没有联网同步，也没有改动原实时数据库。

对每只 ETF，脚本运行包含资金信号与已入库公开资料的研究问题，断言：

- 四个 Agent 都成功，回答状态为 `answered`，资金信号不是 `insufficient_data`；
- 三个指标都有数值，来源日期与副本内原始行情及份额记录的最新日期一致，且不晚于查询日期；
- 至少一条资料来自已识别的官方域名，发布日期不晚于查询日期，回答含资料引用；
- 研究报告已保存、四条工具调用均成功、任务状态为 `completed`；
- Streamlit 在 `live` 模式下针对该 ETF 能生成页面，展示直接回答及四个 Agent 的执行轨迹，无页面异常。
