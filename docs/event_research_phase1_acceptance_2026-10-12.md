# 企业事件研究阶段一验收记录

## 验收结论

阶段一“定义研究契约和人工基准”已完成。此次没有联网采集资料，没有写入真实 ETF 数据库，也没有实现阶段二至阶段六的资料采集、模型编排、证据图谱、竞争性假设 Agent 或 React 事件研究页面。

## 已实现内容

1. `app/models/event_research.py` 定义事件研究 v1 契约：研究计划、事件证据、事实与推断、事件、假设、最终判断、未知项和执行轨迹。
2. 契约限制第一版只研究 `600519`、`601318`、`688981`，窗口不超过30天；事实主张必须有证据，所有引用必须指向报告内存在的对象。
3. `evals/event_research_cases.json` 提供20道人工标注题，覆盖六类问题：事件梳理4题、公告解读4题、跨来源冲突3题、候选原因4题、证据不足3题、未来信息泄漏2题。
4. 每道题包含截止日期、必要事件、有效来源、禁止结论、必要回答点、人工参考答案和人工审核要点。
5. `evals/event_source_catalog.json` 定义8类阶段一来源标识。真实网站均标为 `policy_candidate_unverified`；行情源为 `synthetic_fixture_only`，不表示真实采集已完成。
6. `app/evaluation/event_research.py` 检查结构、研究范围、回答状态、事件覆盖率、时间边界、来源域名和白名单、引用关系、无证据断言、禁止结论及必要回答点。
7. 评分结果始终保留 `manual_review_required=true`。自动分数只证明机器规则通过，不能证明引文忠实、事件解释正确或因果判断合理。
