# 企业事件研究阶段三验收记录

日期：2026-10-12。范围：固定历史窗口 2026-08-14 至 2026-09-13，三家研究对象 600519、601318、688981。阶段三只验收模型规划和并行取证，不验收研究结论。

## 实施与数据范围

- 规划器输出带类型的有向无环任务图。节点记录目标、工具、关键词、依赖、完成条件、失败降级和选择理由。Python 检查公司与日期、工具白名单、参数、环、最多 6 步与 6 轮、30 秒取证时限；独立连接并行读取可执行节点。
- 新增公司日线只读工具。市场记录来自 AkShare 的 `stock_zh_a_hist` 东方财富历史日线接口，采用未复权价格；三个研究对象各 21 个交易日，首日 2026-08-14，末日 2026-09-11。9 月 13 日不是交易日。行情工具只读取本地保存数据，模型给出的 `query` 不能改变公司或日期。
- 本机 `output/event-phase2-20261012-accepted/event_research_phase2.sqlite3` 未被修改。采集脚本先复制它，再只向本机 `output/event-phase3-20261012-acceptance/event_research_phase3.sqlite3` 写入日线。验收库 SQLite `integrity_check=ok`，仍有 6 份文档；行情采集清单保存在同目录的 `market_collection.json`。`output/` 被 Git 忽略，这些文件不随仓库上传。
- 模型规划每次最多一次调用，输出最多 1500 Token，调用后核对总 Token 不超过 3000。费用预算默认单次估算上限 0.01 美元；已知 DeepSeek Flash 按[官方峰时价格](https://api-docs.deepseek.com/quick_start/pricing/)估算，其他模型必须配置单价。调用前使用消息 UTF-8 字节数加协议余量和最大输出长度预估；调用后按服务端 Token 用量复核。该数值是代码估算，实际扣费以服务商账单和当时价格为准。
- `LLM_ENABLED=false` 时开放式事件规划拒绝执行，现有基础资料查询仍可用。会产生模型费用的 HTTP 接口继续要求 `X-API-Key`。

## 真实模型规划验收

完整计划与执行轨迹保存在本机 `output/event-phase3-20261012-acceptance/planning_audit.json`，由已配置的 DeepSeek 模型生成，不随仓库上传。四题分别为事件梳理、公告解读、财务变化和因果追问；四题均取得证据，形成四种不同的“工具 + 依赖”任务图。

| 问题类型 | 主要工具路径 | 执行状态 |
| --- | --- | --- |
| 事件梳理 | 公告、新闻、财务、行情并行，随后综合资料检索 | 取得证据 |
| 公告解读 | 公告与财务资料并行 | 取得证据 |
| 财务变化 | 财务、公告与行情并行 | 取得证据 |
| 因果追问 | 公告、新闻与行情并行，随后新闻复查 | 取得证据 |

四次成功调用合计服务端返回 3212 Token，按峰时单价估算 0.0028554 美元。首次运行中两题因模型输出长度耗尽而失败；将输出上限从 850 调整为 1500 后只重试这两题并通过。首次失败请求也可能产生费用，其服务端用量未被当前客户端记录，因此这里的合计不是本次验收的全部实际费用。此记录不把首次失败抹去，也不将四题当作稳定性或语义正确率统计。

## 程序边界和回归

- 单测拒绝非法工具、越界研究对象、未来日期、循环依赖和超 Token 请求；费用预检查测试确认超预算时模型未被调用。
- 单个节点失败时，其他节点的证据保留，结果为 `partial`，依赖失败节点的后续任务跳过并留有轨迹。
- 关闭模型的注入测试确认开放式规划拒绝执行；真实 HTTP 默认配置为关闭状态，需要明确设置 `LLM_ENABLED=true`。
- `python -m pytest -q`：125 passed；数据库完整性检查为 `ok`。这不证明市场价格与外部行情逐条一致，也不证明规划所得证据足以回答问题。
