# 实习项目交付范围与验证边界

更新日期：2026-10-27。

本项目按**可演示的企业事件研究原型**交付。用户决定跳过阶段五候选解释和阶段六逐题结果的人工语义验收；这些审核不再是本次实习项目的完成条件。2026-10-23 及此前的验收记录仍保留当时的状态和失败案例，不补写人工签名，也不将空白审核表改为通过。

## 本次交付已实现

- 限定三家公司、最多 30 天窗口的用户触发研究流程：来源快照与检索、模型任务规划、事件证据图谱、结构化候选解释、反方检索和保守报告。
- React 研究页显示运行阶段、原文、日期和冲突。证据卡把“模型选作支持/反对”与可定位的原文分开，并标出解释关系未经独立验证；不提供解释成立百分比。
- 只读历史演示、鉴权模型写入、持久化阶段状态、费用上限及失败降级。
- 20 道合成题的两轮角色消融，以及三家公司固定真实图谱的假设阶段单/多 Agent 对照。已有指标只描述这些实验，不是研究结论准确率或生产端到端优势。

## 不作为本次完成条件

- 对所有候选支持关系和最终答案进行人工逐条语义签发。
- 生产端到端单 Agent 与多 Agent 的效果证明、实时全市场覆盖或投资决策级准确率。

跳过人工验收**不等于语义验收通过**。图谱引用能回到原文，仍不能证明模型选择的证据真正支持解释；历史草稿曾出现日期性质和来源独立性错误。对外报告继续保守降级为部分回答或无法判断，模型自由事实句不作为已验证结论发布。项目展示和简历可写“实现多 Agent 企业事件研究原型及可追溯证据卡”，不能写“已证明市场因果”“研究准确率已验证”或“多 Agent 整体优于单 Agent”。

当前项目状态：**实习展示范围的工程功能已交付；解释质量未做独立语义验收。**

本机验证：61 项 Python 测试、5 项前端测试及生产构建通过；只读历史演示的三家公司浏览器检查通过，手机宽度没有横向溢出。这些检查验证功能与展示边界，不提供解释正确率。
