## 本阶段范围

本次把现有研究流程包装成可演示、可调用、可存档和可部署准备的产品形态。当前机器没有 Docker，也没有用户指定的云账号，因此容器配置只做静态检查；实际镜像构建和云上线不列为已经完成。

## 已实现功能

### FastAPI 服务

- `/health`：应用版本、数据库是否存在和写密钥配置状态；
- `/docs` 与 `/openapi.json`：交互式接口说明；
- ETF 列表与历史信号查询；
- 研究任务生成；
- 报告分页存档、单份 JSON 与 PDF 下载；
- 监控、定时任务、同步和提醒日志查询；
- 手动执行一次监控；
- 用户偏好读取与保存；
- 最近一次固定评测结果查询。

生成研究、执行监控和修改偏好属于写操作，必须提供 `X-API-Key`。未设置 `ETF_API_WRITE_KEY` 时返回 `503`，错误密钥返回 `401`。

### Streamlit 产品功能

- 保存默认 ETF、默认数据模式、默认研究问题和报告存档页大小；
- 当前报告一键下载 PDF；
- 浏览历史报告，并下载 JSON 或 PDF；
- 查看手动监控、定时任务和数据同步日志。

偏好保存在独立的 SQLite 配置库，演示数据和真实数据仍分别保存在各自数据库。PDF 包含数据截止日期、五项指标、触发解释、引用、未确认信息、风险边界和研究过程摘要。

### 评测与部署准备

- `evals/questions.json` 中的30个固定问题可通过 `python -m app.cli evaluate --as-of 2026-09-30` 执行；
- 评测结果写入 `output/evaluation/latest.json`；
- Dockerfile 使用非 root 用户、健康检查和中文字体；
- Compose 为数据和输出配置持久化数据卷；
- `.dockerignore` 排除密钥、本地数据库、日志和生成文件。

## 尚未完成及原因

- **实际云部署**：需要用户选择平台并提供对应账号或项目权限；
- **容器运行验收**：当前机器未安装 Docker，无法执行 `docker compose build` 和运行时健康检查；
- **React 前端**：现有 Streamlit 已覆盖作品集演示所需交互，当前阶段继续维护两套前端的收益较低；
- **多用户身份与角色权限**：当前 API Key 适合单人演示，真实多用户产品需要身份服务和权限模型；
- **PostgreSQL 迁移**：当前数据量和单实例演示仍适合 SQLite；多实例写入或云托管时再迁移更合理。
